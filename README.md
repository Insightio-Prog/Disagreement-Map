# Disagreement Map

Paste an argument between two people and see where they actually disagree, what kind of disagreement each point is, and what they already agree on.

- One self-contained `index.html`. No server, no build step.
- Uses the Claude API with your own key, stored only in your browser's localStorage.

## Run it
Open `index.html` in any browser (Chrome, Edge, Safari on iPad).
